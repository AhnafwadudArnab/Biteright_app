# Biteright_app Database

This folder contains the MySQL schema for the Biteright_app project.

## Files
- `biteright_schema.sql`: MySQL schema for users, diet plans, meals, and water intake.

## Usage
1. Open your MySQL client (e.g., MySQL Workbench, CLI).
2. Run the SQL script:
   ```sql
   SOURCE /path/to/Database/biteright_schema.sql;
   ```
3. The database and tables will be created.

You can extend the schema as needed for additional features (e.g., preferences, activity tracking).
